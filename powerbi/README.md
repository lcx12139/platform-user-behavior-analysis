# Power BI 用户行为与增长分析看板

下载[用户行为与增长分析.pbix](用户行为与增长分析.pbix)，或查看[四页看板截图](../assets/dashboard/README.md)。

## 页面结构

| 页面 | 分析内容 |
|---|---|
| 经营概览 | 用户规模、收入、活跃趋势与付费表现 |
| 转化漏斗与购物车流失 | 会话转化路径、放弃率与月度变化 |
| 用户结构与留存 | 新老用户表现、收入贡献与Cohort留存 |
| 用户价值与增长洞察 | RFM分层、复购结构与转化差异分解 |

## 连接与刷新

在Power BI Desktop中打开文件，通过“数据源设置”配置MySQL服务器和数据库连接，再刷新汇总模型。SQL脚本见[执行索引](../sql/README.md)。瀑布图使用手工汇总数据，更新时可接入19号SQL中的动态分解视图。

## 百分比格式

SQL比例已乘以100；[百分比度量示例](percentage_measures.dax)除以100后采用百分比格式。该示例适用于单行bi_conversion_kpi，月度比率应根据对应分子与分母计算。
