# 项目实现

## 数据处理

使用Python完成字段规范化、缺失值处理与去重，使用MySQL构建行为明细、用户月度画像和分析汇总表。

## 分析模块

- 经营指标与活跃趋势
- 用户级与会话级漏斗
- 购物车流失与复购
- 用户结构与Cohort留存
- RFM评分及用户分层
- 转化率结构分解与多维下钻

## 可视化

Power BI通过汇总模型展示四页看板，连接方法见[看板使用说明](../powerbi/README.md)。

数据准备见[下载说明](../data/README.md)，SQL执行顺序见[脚本索引](../sql/README.md)，分析结果见[项目报告](项目分析报告.md)。
