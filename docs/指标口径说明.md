# 指标口径说明（最终版本）

## 时间、实体与金额

| 指标 | 最终定义 | 注意事项 |
|---|---|---|
| 观察期用户 | 任意行为的user_id去重 | 不从只含浏览/加购/购买的汇总表计数 |
| DAU / MAU | 每日/每月任意行为用户去重 | 不过滤非正价格行为 |
| 首次观察用户 | 用户最早出现月份内的活跃用户 | new不是注册；old为后续活跃月份 |
| 行为购买用户 | 任意purchase用户 | 可包含非正价格，不能替代ARPPU分母 |
| Revenue | purchase且price>0的价格之和 | 原始价格单位，无order_id与quantity |
| ARPU | 同期Revenue / 同期活跃用户 | 月份间不可直接平均替代全期比率 |
| ARPPU | 同期Revenue / 同期正价格购买用户 | 最终口径；旧版全部purchase分母已弃用 |
| 正价格购买率 | 正价格购买用户 / 活跃用户 | 不等于漏斗完成用户 / 浏览用户 |

时间按UTC解析后去时区存储，不转换为北京时间。比例SQL一般输出0—100数值；Power BI若使用百分比格式，需要先除以100。只有单行汇总视图适合示例DAX中的SUM，跨月比率应从分子分母重新计算。

## 漏斗与放弃

用户宽口径：同一用户出现浏览、加购、购买，不看顺序。月度版本要求行为在同一月份。严格近似条件为 `first_view_time < first_cart_time < first_purchase_time`，分别在用户或Session上计算。

浏览→加购以浏览实体为分母；加购→购买以满足前两步的实体为分母；整体以浏览实体为分母。所有后续阶段都嵌套在前一步中，不使用互不相关的事件人数相除。

全加购放弃：首次加购存在，首次购买缺失或不晚于首次加购。转化：首次购买晚于首次加购。不要求浏览，因此其12.71%转化率不同于严格Session漏斗的12.15%。

移除信号要求首次移除晚于首次加购；静默放弃=放弃−放弃且合格移除。此定义不能保证整个会话完全没有移除。月度放弃归属首次加购月份，购买/移除时间未另行限制为当月。

## 同期群留存

用户首个观察月份为Cohort，后续月份任意行为视为活跃。Mn为第n个自然月活跃人数/M0人数，不要求连续活跃。末端月份的未观察单元格为缺测，不填0。2019-10混合窗口前已存在的用户，跨群比较优先看2019-11以后。

## RFM与分层优先级

仅使用正价格purchase。R=`DATEDIFF('2020-03-01', MAX(event_date))`，不是距离今天；F=`COUNT(DISTINCT user_session)`（非NULL），近似购买订单频次；M为累计正价格购买金额。

前置检查：正价格购买记录的NULL和空字符串Session分开检查，F最小值必须≥1。旧NULL检查为0不等于自动证明空字符串也为0。

| 分数 | R：距基准日天数 | F：不同购买会话数 | M：金额累计分布 |
|---|---|---|---|
| 1 | >120 | 1 | ≤20% |
| 2 | 91—120 | 2 | (20%,40%] |
| 3 | 61—90 | 3 | (40%,60%] |
| 4 | 31—60 | 4—5 | (60%,80%] |
| 5 | ≤30 | ≥6 | >80% |

M使用`CUME_DIST()`，同金额获得相同累计分布，分组人数不一定各20%。F不使用NTILE。分层按下表顺序命中后停止：

| 优先级 | 分层 | 条件 |
|---|---|---|
| 1 | 核心价值用户 | R≥4且F≥3且M≥4 |
| 2 | 高价值复购用户 | R≤3且F≥3且M≥4 |
| 3 | 潜力用户 | R≥4且(F≥2或M≥3) |
| 4 | 新近单购用户 | R≥4且F=1，且未命中前项 |
| 5 | 沉睡用户 | R≤2且F≤2且M≤3 |
| 6 | 流失风险用户 | R≤2且(F≥3或M≥4)，且未命中前项 |
| 7 | 一般用户 | 其余 |

表中R/F/M条件指分数，不是原始天数/频次/金额。分层互斥；复购（原始F≥2）是另一套切分，可横跨多个分层，不能与“高价值复购用户”混用。

## 异动分解与价格研究

11月相对12月：结构项Σ(w11−w12)c12；组内项Σw11(c11−c12)。w是各新老用户组占当月浏览用户的比例，不是MAU占比；c是该组月度宽口径整体转化率。结果单位为百分点，公式选择会影响各项归属，但总差异不变。

Peak为11月21、22、23、24、28、29、30日，Normal为11月其他日期。价格带使用(0,5)、[5,10)、[10,20)、[20,50)、[50,+∞)。价格带漏斗仅使用price>0的全部行为，实体为用户日×价格带，不要求同商品或事件时序。同人同日可属于多个带。

品牌份额分母为各时间段正价格购买事件；`Unknown`计入以显示缺失影响。品类缺失按NULL、空串或Unknown统计，分母为2019-11全部行为。
