# 数据质量与局限性

## 清洗和导入

- 单个月文件在事件类型、时间和价格规范化后做全字段去重，再填充品牌/品类Unknown；没有新增跨文件去重规则。
- 品类ID始终字符串保存。brand、category_code缺失填Unknown；非正价格和缺失Session行为保留。
- 2020-02零价格53,812条均非purchase；另有34条负价格事件，其中32条为purchase，金额计算必须排除这些负价格购买。
- 旧CSV派生字段名year_month/hour/weekday与当前event_month/event_hour/event_weekday位置相同；LOAD DATA按位置映射。CSV必须按CRLF导入，每次导入后检查SHOW WARNINGS。
- 日期或价格解析失败沿用`errors='coerce'`，不得把无效时间衍生出的周末False当作有效工作日证据。

## 缺失会话与首次事件近似

pandas的缺失Session可能写成空CSV字段；旧LOAD DATA直接写入VARCHAR，旧汇总只过滤`IS NOT NULL`，不排除空字符串。最终SQL保留历史口径并添加NULL/空串检查；若发现空串合并或同Session对应多个用户，需要先记录影响，再重算相关结果。

首次时间算法会排除时间相等的动作，可能漏掉早期乱序后的有效后续路径，也不要求同商品。静默放弃只说明没有合格首次移除信号；跨会话购买也可能发生。RFM的Session频次不是订单数。

## 字段缺失与不可归因事项

2019-11的category_code缺失率为98.32%，不用于最终品类原因归因。品牌在购买事件中Unknown约43%，对品牌排名和份额解释有明显限制。没有注册时间、营销活动、流量渠道、优惠、支付结果、order_id或quantity；不推断具体促销、支付故障、订单GMV或用户真实注册增长。

2019-10存在观察起点左截断；末端同期群没有足够后续观察期。次月未活跃不代表永久流失。新老用户比较存在留存选择性；分解和价格分层不能证明因果。
